# What's new in 0.1.1

**Included in Free.** Learnomy has no paid version.

Fixes from the 0.1.0 review. No new permissions. After updating, run the site kit command again with `v0.1.1` (see [After every update](../getting-started/install.md#after-every-update)): the catalog, course and lesson pages and `learnomy.ts` changed.

- **Find shows the matches.** On Enrollments and Quiz results, the count shows how many rows match, and **Next page** pages through all of them.
- **One access rule.** A course with no value in **Who can read the lessons** shows as Members on the catalog and course page, the same as its lessons. See [What Members means](../getting-started/what-members-means.md).
- **Catalog Previous** goes back one page instead of to the first page.
- **Faster admin lists on big sites:** two storage indexes for the newest-first lists. EmDash adds them when it loads the plugin; nothing to do.
- **On Cloudflare, redeploy after installing or updating** is now in the registry Installation text too.
