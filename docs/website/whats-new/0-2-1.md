# What's new in 0.2.1

**Included in Free.** Learnomy has no paid version.

Fixes to retake counts. No new permissions. After updating, run the site kit command again with `v0.2.1` (see [After every update](../getting-started/install.md#after-every-update)): `learnomy-strings.ts` changed.

- **Erasing never resets a limit set later.** When a member erases their own course data, the site keeps how many attempts they used and when for every quiz they took, not only quizzes limited at that moment. If you later give a quiz a maximum number of attempts or a wait, attempts made before the erase still count.
- **No counts left behind for deleted quizzes.** A member's own erase also removes the kept counts of quizzes you have deleted.
- The admin erase still removes everything, so you can reset a member's retake limits from Enrollments or Quiz results.
