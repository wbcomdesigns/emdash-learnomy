# What's new in 0.2.2

**Included in Free.** Learnomy has no paid version.

Fixes. No new permissions. The site kit did not change, so there is nothing to copy again after updating.

- **A clear first step on a new install.** Right after installing from the registry, before you copy the site kit, the Learnomy dashboard card and the Course outline page say "Next: copy the site kit" with a link to the install guide, instead of a plugin error.
- **One progress number everywhere.** Enrollments now counts published lessons only, the same number the member sees on their course page. A draft lesson in a course outline no longer makes a member look a lesson behind, and a lesson you publish after they finished shows as one more to do on every screen.
- **Quiz settings say what is wrong.** A pass mark outside 1 to 100 (0 means none), an empty pass mark, or attempts or a wait out of range is refused with a message saying what is allowed. Nothing is saved. Agents using `saveQuiz` get the same message.
- **10 rows a page** on Enrollments and Quiz results.
- **Clearer guides.** [Let members join](../getting-started/let-members-join.md) now starts with setting up email, says to change the role from Author to Subscriber, explains what "Invitation sent" means, and shows where the invite link is on a local test site.
