## 0.1.0

The first release. Needs EmDash 1.5.0 or later.

- New      - Courses and lessons in EmDash's editor, with a Course outline page to set each course's lessons and order.
- New      - Open or Members courses; Members keeps lesson text away from guests.
- New      - Free enrollment, Mark complete and progress.
- New      - One quiz per lesson, up to 20 questions, scored on your site.
- New      - Your courses for members, Enrollments and Quiz results lists, erase for one member, a dashboard card.
- New      - MCP tools for outlines, quizzes and lists, so an agent can build a whole course.

New permissions: Read your content, Read user accounts.
